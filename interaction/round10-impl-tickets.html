切片原则 为什么是这 8 张
  • 风险前置:票 02 = SPEC 定义的第一里程碑(签名链翻译 + 线上探针钉死),X-Gorgon 是全项目最大风险,第 02 张就消化
  • 每张纵向到底:接口 → 解析 → UI → 焦点 → 本地存储,切完即可在电视上演示,不按"接口层/UI 层"横切
  • 详情页先于首页:首页三行要三个数据源(推荐 API + 榜单 HTML + 本地断点),而详情页只吃一个接口——更窄的子弹先飞
  • 首张业务票带调试入口(硬编码 series_id),搜索/首页就位后自然替换,不阻塞演示
