## Question

v1 全部页面（首页/分类、搜索、详情+选集、播放器、追剧+历史、收藏）的布局草案、焦点流转规则、遥控键映射表是什么？——这是页面级 spec 的核心生产票。

## 输入

- 基线：左侧竖直导航栏（票 02）、v1 功能清单、blbl 借鉴点清单（票 06）。
- 红果数据形状（票 07 的接口对接事实，若已完成可细化首页行结构）。

## 产出方式

- 低保真页面布局（ASCII 或 HTML 草稿）+ 每页焦点流转说明（方向键如何移动、边界如何回绕、返回键行为）+ 遥控键映射总表。
- 以交互式 HTML 给用户过目确认（prototype 票的 HITL 环节），重点确认：焦点边界行为、选集大列表（95 集）交互、播放器内控制层。

## Resolution

2026-10-20 用户通过 `interaction/round4-ia-design.html` + `interaction/round5-mvp-scope.html` 两轮拍板（round5 答案原文存档于会话）。

### 第一期范围（找剧 + 看剧 MVP）

侧边栏 **3 项：首页 / 搜索 / 历史**。

第一期做：
- **首页三行**：继续观看（断点续播入口，进页焦点）/ 热播榜 / 为你推荐；无 banner 运营位；仅"继续观看"行尾有"更多›"（= 历史页）
- **搜索**：输入框 + 联想词 + 键盘 + 结果网格（交互细节 → 票 11）
- **详情+选集**：左栏海报资料 + 单一"继续播放"主键（无收藏/追剧按钮）；右栏选集 50 集/组 tab，已看灰显、当前集橙框
- **播放器核心**：竖屏 9:16 居中、自动连播、断点续播（位置每 5s 落盘，WatchEntry 结构）
- **历史页**：独立页、纯网格无筛选（Q3 拍板"独立历史页 · 侧边栏 3 项"；round5 清单默认"延后"被此确认覆盖）

延后二期：追剧页（4 筛选 tab + 追更提醒）、收藏页 + 收藏按钮、设置页、长按 OK 快捷菜单、倍速、系列/多季聚合、榜单完整页、MENU 键功能。

### 播放器操作逻辑（Q1 用户自定义，blbl 式）

- 纯净态：**←→ = seek ±10s**；**↓ 呼出选项栏**（OK 同样呼出——补充的 TV 惯例默认，spec 可调）
- 选项栏五项，**默认焦点【暂停/播放】**：【暂停/播放】【上一集】【下一集】【选集】【设置】
- 【选集】→ 全屏选集浮层（50 集/组 tab、8 列网格、已看灰显/当前橙框、返回关闭）
- 【设置】→ 播放设置面板：第一期 = 清晰度档位（CDN 直链实际可选）+ 自动连播开关；倍速二期
- 收起：↑ / 返回 / 5s 无操作自动收起（补充默认，spec 可调）

### 键位与交互全局规则（第一期）

- **只用方向 + OK + 返回三键**；零长按、零 MENU（兼容无 MENU 键的国产盒子遥控器）
- 侧边栏进出：焦点在行首按 ← 进侧边栏（简单判定，弃 round4"几何检测"复杂版）；侧边栏 → 回内容区恢复焦点
- 网格：行内 ←→、跨行 ↑↓ 保持列位；页面切换 show/hide 复用（blbl 机制，切页不丢状态）
- 返回四级链：关浮层/选项栏 → 退播放回详情 → 回上级页面 → 首页双击退出（1.5s 提示）
- 清晰度默认 1080P；焦点视觉 1.04x / 120ms 缩放 + 2dp 描边、零阴影（blbl 参数）；竖版海报卡 9:16 + 角标（集数/状态）+ 底部进度细条
