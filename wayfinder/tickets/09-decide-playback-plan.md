### 取流链路（Q1 拍 b：只用主链）

- **第一期只用 App 取流接口 `video_model/v1` + Ladon/Argus 修复**（约 6 行，票 04 已在线验证：3 次稳定 / 换集泛化 / 端到端解析出 1080P CDN 直链 + CENC 密钥）
- 三级链的 Web 播放页备链、djapi 第三方兜底**不进第一期**
- 残余风险（用户知情接受）：主链被服务端风控升级（校验真实 Ladon 算法）时无备用通道，靠空响应监控发现 + 发修复版本

### 错误重试/降级规范（Q2 拍 a，按单链语境调整）

| 场景 | 策略 |
| --- | --- |
| 取流失败 | （200+0 / 网络错 / 超时 8s）→ 同链路重试 2 次（指数退避 1s / 3s）→ **主链响应内多线路 URL 切换**（main_url → backup_url*，Q1 单链语境下的"降级"）→ 全失败 → 错误提示页 |
| 播放中断流 | Media3 错误 → 从当前位置自动重连（重新取流）→ 3 次失败 → 错误提示页；断点不丢（5s 落盘） |
| 换集失败 | 按"取流失败"策略；期间 OSD 提示"正在切换…" |
| 错误页 | 仅两键：OK = 重试（从断点）、返回 = 退回详情页；错误码 E-1xxx 取流 / E-2xxx 播放器（spec 附表） |

### 空响应监控（Q3 拍 a：第一期做）

- 后台计数 200+0 次数 + 本地日志；**≥3 次/天**视为风控升级信号
- 无 UI 展示（设置页已延后，票 10）；二期随设置页补展示入口

### CENC 与播放集成（2026-10-20 按票 13 修订：纯 Kotlin）

- CENC 由 Kotlin 侧 **Media3 自定义 DataSource** 处理：spade_a → AES-128 密钥解出（Kotlin 翻译）+ 边读边 AES-CTR 解密；不再使用 Go 本地流服务
- 清晰度默认 1080P（跳过 bytevc2 编码）；【设置】面板给清晰度选项（票 10），降级路径 720P
- Ladon/Argus 修复（票 04）直接包含在 Kotlin 签名链里
